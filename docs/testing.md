# Testing Plan

## ALU Testing
The ALU will be tested for:
- ADD
- SUB
- AND
- OR
- XOR
- NOT
- ZERO flag behavior
- CARRY flag behavior

## Register Testing
The register module will be tested for:
- reset behavior
- load behavior
- hold behavior

## PC Testing
The PC module will be tested for:
- reset
- increment
- load for jump instructions

## CPU Testing
The CPU will be tested for:
- fetch, decode, execute flow
- arithmetic instructions
- memory load/store
- branch behavior
- halt behavior

## Tools
- Icarus Verilog
- GTKWave
