# Project Specification

## Objective
Build a custom 4-bit accumulator-based CPU in Verilog that demonstrates CPU architecture, RTL design, modular design, and verification.

## High-Level Design
- Data width: 4 bits
- Instruction width: 8 bits
- Architecture type: accumulator-based
- Execution model: multi-cycle
- Main states: FETCH, DECODE, EXECUTE

## Core Components
- ALU
- ACC register
- PC
- IR
- flags
- instruction memory
- data memory
- control unit

## Expected Outcome
A fully simulated CPU capable of executing a small custom instruction set and documented clearly on GitHub.
