# 4-bit CPU in Verilog

A custom 4-bit accumulator-based CPU designed in Verilog as a computer architecture and digital systems project.

## Project Goals

- Design a simple custom CPU from scratch
- Implement a 4-bit ALU and supporting datapath
- Build a multi-cycle control unit
- Simulate and verify execution using testbenches
- Document the architecture and engineering process on GitHub

## Planned Architecture

- 4-bit data width
- 8-bit instruction width
- Accumulator-based design
- Multi-cycle CPU
- Instruction memory: 16 x 8
- Data memory: 16 x 4
